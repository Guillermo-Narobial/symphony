🤖 Ejecutor

El agente `narobial-frontend` resuelve la issue end to end

1. PreparaciónLee `AGENTS.md`, `INSTRUCTIONS.md` y detecta perfil de testing.
2. ImplementaciónRespeta design system `nb-`, i18n, CSS variables y seguridad.
3. VerificaciónEjecuta tests unitarios, cobertura y valida estados de UI.
4. PRCommit, push y PR contra `hotfix-master`.
5. PreviewBuild Docker + nginx en qdevweb con SSL.
6. RegistroCHANGELOG.md y decisiones técnicas.

🛡️ Seguridad

Tres capas: secretos, CVEs y análisis profundo

🔑 gitleaksDetecta secrets expuestos y abre issues críticas.
🧾 npm auditFiltra vulnerabilidades high y critical con fix sugerido.
🔍 kiro-cliBusca XSS, CSP, sanitización, memory leaks, bugs y UI.

Cada finding se convierte en una issue independiente con severidad, archivo, línea e instrucciones para el agente.

📈 Mejora continua

Tests, documentación y dependencias se revisan de forma recurrente

🧬 Mutation testingStryker detecta tests débiles y abre issues por archivo.
📝 Docs checkerGenera JSDoc para código nuevo y abre PR revisable.
📦 Deps checkerActualiza patch/minor, ejecuta audit fix y publica resumen.
ObjetivoMenos deuda técnica acumulada.
ControlTodo entra como issue o PR revisable.
