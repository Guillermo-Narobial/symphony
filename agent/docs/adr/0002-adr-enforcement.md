# ADR-0002: Enforcement de decisiones arquitectónicas\n\n- Estado: Aceptado\n- Fecha: 2026-07-15\n- Responsable: Narobial Engineering\n\n## Contexto\n\nADR-0001 estableció que los cambios de arquitectura y automatización deben documentarse, pero la regla era solo normativa. Un cambio futuro podía pasar revisión sin crear un ADR.\n\n## Decisión\n\nSe añade `scripts/check-adr-required.sh`, invocado por `npm run build`. Si el diff incluye código, unidades systemd, configuración de seguridad, despliegue o workflow, debe incluir un ADR nuevo con formato `docs/adr/NNNN-titulo.md`. Los cambios exclusivamente rutinarios o de documentación no requieren ADR.\n\n## Consecuencias\n\nLos cambios relevantes fallan de forma explícita antes de integrarse si no dejan trazabilidad. La regla evita burocracia para cambios que no alteran decisiones de diseño.\n\n## Reversión\n\nSustituir este ADR por otro que modifique el guard y su integración en el build.\n
